# Browser issue creation client

Slice237 adds a typed client, not mutation UI. Caller supplies a canonical project UUID, expected actor UUID, canonical idempotency UUID and title/optional description/assignee. Validate and serialize a private snapshot synchronously before fetching current-session/CSRF, so input edits while awaiting cannot change an uncertain operation. Do not trim/normalize serialized text: the server fingerprints the raw values. Reject null/unknown fields, lone surrogates, invalid trimmed scalar title bounds, description beyond65536 UTF-8 bytes and JSON beyond512KiB before any fetch. Use Unicode White_Space for the Rust trim boundary, not JavaScript's different trim set.

One explicit call fetches current-session once and requires its actor to match the caller's expected identity, then sends one POST with exact bearer-bound CSRF and supplied Idempotency-Key. Cookie rotation/switch between requests fails CSRF closed. Native browser supplies Origin; never synthesize Host/Origin/Authorization or accept arbitrary paths/methods. Same-origin credentials/mode, no-store, redirect:error, shared8s abort deadline. No generated replacement key, retry loop or retry based on retryable/Retry-After. A timeout, lost/malformed response or failed validation after POST is an uncertain commit, not evidence of rollback. Caller must preserve request/key and explicitly reconcile; identity mismatch must not replay a prior principal's uncertain operation into another principal namespace.

Accept only201 JSON with bounded strict content-free receipt, canonical UUID/project match, positive i64 decimal strings, issue key/number agreement, created_version1, exact relative Location and Idempotency-Replayed true/false. Share bounded fatal-UTF8 JSON/error decoding with the existing issue clients, without widening their read API or adding an arbitrary write transport. Never retain server error text, request/CSRF/key/title/description in exceptions or logs; expose existing safe IssueRequestError metadata. Do not cache receipts/commands in localStorage, sessionStorage, service worker or URL. No outbox publication/provider traffic is added.

Vitest protocol-boundary fake fetch verifies validation-before-network, immutable snapshot, identity/CSRF refresh, fixed POST/options/headers, DTO corruption/bounds/headers, replay, no retry on failures and caller abort/deadline. This supplements real router/SQLite tests from236, not a browser HTTPS wiring claim; UI and actual form journey follow separately.
