# Expected-version text replacement client

Slice243 adds a fixed-path typed PUT client, not an editor. Caller supplies project UUID, target immutable issue UUID plus canonical number, expected actor UUID, stable request key and full title/optional description/expected_version decimal string. Validate all selectors/version/strict field allowlists/text/UTF-8/body budgets and snapshot raw values before fetching current-session. Reuse creation's text validation without accepting assignee/other fields. Omitted description clears; expected_version is never a JS number. Compare current actor before one CSRF-bound same-origin PUT, no-store/redirect:error, shared8s deadline. Do not synthesize Origin/Host/Authorization in the bundle.

Only200 strict4KiB receipt accepted: exact project/issue UUID and number, key suffix agreement, changed boolean and result_version exactly expected_version for no-op or expected_version+1 for change, bounded by positive i64. Replay receipt describes the original command and is validated against its original expected version, not a subsequent state. Require exact relative Location and Idempotency-Replayed true/false. Safe shared errors retain only status/code/request_id/retryable, not server/private text. A version conflict is not automatically retried or rebased; the UI must preserve the draft and reload explicitly. Network/abort/invalid success can be an uncertain commit; never generate a new key or silently resend. Expected actor mismatch prevents transferring a retained command to another principal.

Unit protocol-boundary tests verify immutable snapshot, lossless version/no-op arithmetic, malformed DTO/header/media/size rejection, identity/input/abort-before-send and exactly one PUT on conflict/network/timeout. Extend real Node client→HTTProuter→SQLite fixture with edit/readback/no-op/replay/conflict, discarded committed PUT response then explicit same-key recovery, and exact versions/history/outbox/receipt counts. This is not HTTPS editor/draft-reload certification. No persistence, editor, automatic retry, provider call or outbox delivery added.
